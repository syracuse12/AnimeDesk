# AnimeDesk independent review — 23 November 2026

Verdict for a friends-only Windows distribution: **BLOCKED**. The reviewed local
build passes the checks below, but a distributable package and rights clearance
are not yet in place. No application or installer was published.

## Security repairs

- Browser artwork uses opaque server-minted tokens. HTTPS sources are checked
  before use; each DNS answer and redirect is checked against the public-address
  policy and pinned to the connection. The route has an eight-second timeout,
  8 MiB response cap, byte-signature checks for JPEG, PNG, WebP, GIF and AVIF,
  no forwarded credentials, and a 32 MiB image cache. Unsupported or missing
  images fall back to initials. Local sidecar artwork is re-minted after a
  service restart.
- AniList POSTs use the fixed `https://graphql.anilist.co` endpoint through the
  guarded resolver, reject redirects, time out after 12 seconds, cap responses
  at 512 KiB, and reject malformed JSON structures. The 500-entry title cache
  remains bounded. Confident title matching and MAL ID resolution passed.
- The local API still binds to loopback and checks Host, Origin, and browser
  fetch metadata. The normal launcher now asks for an available loopback port
  and opens a window only after its own child server reports readiness.

## Reliability and verification

- Late detail responses cannot replace newer selections. Resume chooses the
  most recently updated unfinished episode. Failed history writes now trigger
  a visible event, and failed writes no longer appear as saved in memory.
  Player overlay labels have solid dark backing on bright frames.
- `npm run verify`: typecheck passed; 96/96 tests passed; build passed with a
  non-failing bundle-size warning.
- `npm run test:ui`: 22/22 stages passed, including four decoded search posters,
  decoded detail artwork, search, detail, playback, Next/Previous, skip controls
  and autoplay.
- `npm run test:qa`: AniSkip 11/11; autoplay 21/21; persistence 13/13;
  mpv fallback 11/11; screen capture and corrupt-file error flow passed.
- `npm run test:continue`: 20/20, including real playback, persisted history,
  decoded card artwork and resume. `npm run test:live`: 33/33, including live
  sub and dub playlists and media segments, subtitle proxy, AniSkip and dubbed
  mpv playback.
- `npm audit --omit=dev --audit-level=low`: zero reported runtime package
  vulnerabilities on the review date. This is not a complete supply-chain
  assessment. Lockfile package integrity fields are present.

## Distribution blockers and limits

- No installer or self-contained release package exists. First run requires
  Node 24+, npm dependencies, Edge or Chrome, and a writable build location if
  `dist` is absent. App data uses `%APPDATA%/AnimeDesk` and the browser profile
  uses `%LOCALAPPDATA%/AnimeDesk`; these paths need a clean-user install test.
- The bundled mpv file is excluded from Git. A future package must include a
  checksum-verified binary and meet mpv, FFmpeg and other dependency notice and
  source obligations. The unsigned executable may trigger Windows SmartScreen;
  recipient-machine Defender compatibility has not been measured.
- The `hianime` integration is unofficial scraping and has no demonstrated
  redistribution or playback rights for recipients. Internet Archive collection
  membership does not establish that an item is public domain. The UI no longer
  labels the whole collection as public domain. A release must allow only media
  sources each recipient is authorised to access, with provider terms reviewed.
  [AniList API terms](https://docs.anilist.co/guide/terms-of-use) also govern
  its metadata use.
- Local browser request guards do not authenticate other processes running as
  the same user. Public hosting is outside this design. The browserless fallback
  keeps the server running until its launcher is stopped; crash and shutdown
  behaviour still need testing on clean Windows machines.
